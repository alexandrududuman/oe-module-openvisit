# Security policy

OpenVisit handles live clinical conversations. Security reports are taken seriously and handled
privately.

## Reporting a vulnerability

Do not open a public issue for a security problem.

Report it privately with **Report a vulnerability** on the
[Security tab](https://github.com/alexandrududuman/oe-module-openvisit/security/advisories/new),
or email **alexandru@thepenguindeveloper.com**. Include:

- the module version and the OpenEMR version
- steps to reproduce, or a proof of concept
- the impact as you understand it

You will get an acknowledgement within 72 hours and a fix or a mitigation plan within 14 days
for confirmed issues. Credit is given in the changelog unless you prefer otherwise.

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.6.x   | yes       |
| < 0.6   | no        |

Only the latest minor release receives security fixes.
